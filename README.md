# Heart Disease Analytics Dashboard

**Author:** Pratimaan Tripathi

This project analyzes patient health data to identify potential heart disease risk patterns using SQL-based data cleaning, exploratory data analysis (EDA), feature engineering, and interactive visualization in Power BI.

---

##  Tools & Technologies Used

- **MySQL** – Database creation, data cleaning and transformation
- **SQL** – Data querying, analysis and feature engineering
- **Power BI** – Interactive dashboard and data visualization
- **EDA** – Exploratory analysis of patient and heart disease patterns

---

##  Key Features

- Cleaned and validated **916 patient records** using SQL.
- Handled missing values, invalid entries and outliers.
- Created derived features such as **age groups and outlier flags**.
- Performed EDA across **age, gender and chest pain type**.
- Identified important heart disease risk patterns.
- Built an interactive **Power BI dashboard** with:
  - KPI cards
  - Bar charts
  - Pie charts
  - Line charts
  - Interactive filters
- Analyzed indicators such as **cholesterol, maximum heart rate and heart disease percentage**.

---

##  Key Insights

- Patients above **60 years** showed a higher heart disease rate.
- Age and chest pain type showed noticeable relationships with heart disease occurrence.
- Cholesterol and maximum heart rate were analyzed as important cardiac indicators.
- Interactive filtering allows users to explore risk patterns across different patient groups.
